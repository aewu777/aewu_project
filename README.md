# AEWU Project

A collection of small projects built with Reflex.

## Tech Stack

- [Reflex](https://reflex.dev) — full-stack Python web framework.
- Python 3.14+
- Tailwind CSS v4

## Getting Started

### Prerequisites

- [uv](https://docs.astral.sh/uv/)
- Python 3.14+

### Install & Run

```bash
git clone https://github.com/aewu777/aewu_project.git
cd aewu_project
uv sync
uv run reflex run
```
